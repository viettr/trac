# Plot trac coefficient path

Plot trac coefficient path

## Usage

``` r
plot_trac_path(fit, iw = 1, coef = c("alpha", "beta", "gamma"))
```

## Arguments

- fit:

  an object as returned by
  [`trac`](https://viettran.de/trac/reference/trac.md).

- iw:

  index specifying which weight sequence solution to plot

- coef:

  which type of parameter to show in the plot
