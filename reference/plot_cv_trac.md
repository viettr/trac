# Make a plot of the output of cv_trac

Make a plot of the output of cv_trac

## Usage

``` r
plot_cv_trac(cvfit_trac, iw = NULL, superimpose = TRUE)
```

## Arguments

- cvfit_trac:

  an object as returned by
  [`cv_trac`](https://viettran.de/trac/reference/cv_trac.md).

- iw:

  vector of indices specifying which weight sequence solutions to
  include

- superimpose:

  whether to superimpose
